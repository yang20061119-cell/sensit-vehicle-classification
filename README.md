# SensIT Vehicle Classification

DS4400 midterm project.

Dataset: [SensIT-Vehicle-Combined (OpenML 1593)](https://www.openml.org/d/1593)

Goal: classify each sample as AAV, DW, or noise using 100 sensor features.

## Files

- `DS4400_SensIT_Vehicle_Classification.ipynb` — main notebook
- `requirements.txt` — Python packages

## How to run

```bash
pip install -r requirements.txt
```

Or open the notebook in Google Colab and run all cells.
